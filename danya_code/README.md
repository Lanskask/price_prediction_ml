# Описание итераций решения

По состоянию на 23.10.25 решение из файла `v23_10_baseline` имеет качество чуть лучше случайного предсказания.
Поэтому точно нужно улучшать качество.


*По следующим шагам для улучшения можно попробовать следующее:*

**Шаг 1: Добавить технические индикаторы.**
RSI, MACD, Bollinger Bands

**Шаг 2: Улучшить работу с новостями.**
Добавить использование эмбеддингов для улавливания взимосвязей из текстовых данных по новостям.
Можно попробовать FinBERT.


**Если после шагов 1-2 улучшилось качество, то здесь можно сразу перейти к шагу 5 для понимания, где сейчас ошибается модель и где возможно еще улучшить предсказание**

**Шаг 3: Другая целевая переменная.**
Волатильность вместо изменения цены.
Меняем задачу регрессии на задачу бинарной классификации (up/down)
Взвешивание по важности

**Шаг 4: Ensemble методы**
Разные модели для разных режимов.
Stacking и weighted voting

**Шаг 5: Outlier detection (работа с выбросами) + анализ ошибок (ErrorAnalysis)** - этот шаг делаем, когда на предыдущих шагах качество выросло, то есть есть смысл уже делтально анализировать и смотреть на каких объектах ещё модель плохо предсказывает и где можно улучшить.

Анализировать точки с большими ошибками (справляется с ними модель или нет).
В этом же шаге смотрим анализ ошибок (здесь уже смотрим не одну метрику как раньше MSE, MAE, MAPE, а раскладываем её на составляющие. Это даёт нам понять, где конкретно система показывает себя хорошо или плохо).
В Error Analysis можно посмотреть:
- "остатки" и "псевдоостатки" модели
- анализ распределение остатков
- анализ best/worst/corner кейсов работы модели

Huber Loss вместо MSE
